VERIFIED: 2026-10-14, independent check against the official FM 3-90, ATP 3-21.8 (C1) and ATP 3-21.10 (1 June 2026) PDFs. All other claims verified verbatim. Finding applied: the withdrawal/exfiltration note corrected to say FM 3-90 uses "withdrawal" while ATP 3-21.8 and ATP 3-21.10 use both terms.

[resolved] PROBLEM 1 (WRONG, claims 16 and 15 note): page.html line 148 says "Where FM 3-90 and ATP 3-21.8 say 'withdrawal,' ATP 3-21.10 says 'exfiltration.'" ATP 3-21.8 para 7-107, p. 7-32 itself says "the fundamentals of the raid include ... a planned exfiltration" (the page quotes this two paragraphs earlier) and also "The planned withdrawal allows friendly forces to move off of the objective". Points for the checker:
- Para 7-113 note says fires are chosen "at my command or time on target" for a raid; the page does not state a fire-control method.
- The page says "the response force is alerted when the fires open". That is the model's timing; the doctrine says only that response forces "will be alerted once the engagement begins" (7-102).
- The raid's phase names and "withdraws ... usually using a different route" are FM 3-90 and ATP 3-21.8; the figure draws a different return route (a drawing choice consistent with those).
- The order in which the support and security elements withdraw in the Battlefield view (assault first, then support, then security) follows para 7-120.
