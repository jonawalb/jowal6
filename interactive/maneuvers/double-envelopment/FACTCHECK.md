# Double Envelopment: fact check

VERIFIED 2026-10-13 by an independent fact-checker (FM 3-90, 1 May 2023, via Wayback; Britannica via Wayback; Polybius 3.115, Paton, LacusCurtius). All seven claims are exact. After the check, the Cannae sentence now credits "military historians", as Britannica does.

Every factual claim on the page, with the source opened while building (2026-10-13). The official FM 3-90 host (armypubs.army.mil) did not resolve from the build machine, so the PDF was read from the Internet Archive copy of the same URL (web.archive.org/web/2024id_/https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN38160-FM_3-90-000-WEB-1.pdf).
